Updating your data

This site has no database — your sales and inventory live in eight plain CSV files (four sold, four unsold). Two ways to update them:

1. Permanently (redeploy): export from each marketplace as CSV, replace the matching file in /data — poshmark.csv / mercari.csv / depop.csv / vinted.csv for sold, or the *-unsold.csv versions for still-listed items — keep the same column headers (or see README.md for the alias list this page recognizes), then redeploy on Netlify.

2. Preview only (this browser tab, right now): pick sold or unsold, a platform, and a CSV file below — it merges into the tables without touching your deployed files. Refresh the page and it's gone.
